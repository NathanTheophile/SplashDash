# SplashDash

GDD Splash & Dash



## Concept

Un party game où vous incarnez un poisson qui doit éjecter ses adversaires à l’aide de ses courants et de son dash.

Ambiance île tropicale / détente mais avec un gameplay rapide et nerveux (bruitages rigolo / cartoonesque)


## 3C

**Caméra :** Top Down, 2D.

**Controls :** Clavier : 4 touches de déplacement remappable + 1 touche de dash remappable.
                Manette : Joystick gauche pour déplacement + 1 bouton pour dash.

**Character :** Poisson de différentes couleurs / skin.


## Gameplay

**Actions du joueur :** 

Déplacement → Si le déplacement est effectué de manière à creuser le sable, le poisson a une vitesse ralentie.

Si le déplacement est effectué dans l’eau, la vitesse du poisson est normale.

Si le déplacement est effectué sur un courant marin, la vitesse du poisson est augmentée.

Dash (création du courant) → Si le joueur effectue un dash dans l’eau, sa vitesse est augmentée et une zone de courant marin apparaît derrière lui, propulsant tout joueur entrant dans cette zone dans la direction du courant.

Si le joueur effectue un dash en creusant le sable, la vitesse du poisson est augmentée mais moins que lors d’un dash effectué dans l’eau.

Si le joueur effectue un dash dans un courant marin, son dash, override l’ancien.

Si le joueur effectue un dash dans un courant marin, dans la même direction, le joueur est propulsé extrêmement fort dans la direction du dash. A ce moment-là, s' il rencontre un autre joueur, il propulse l’autre joueur instantanément sur les bords de map, s' il ne rencontre personne, il est propulsé sur les bords de map.

Si le joueur dash touche un adversaire, l’adversaire est “sonné” pendant une certaine période de temps.
